 Best Time to Buy and Sell Stock

📌 Problem

Given an array "prices", where "prices[i]" represents the price of a stock on the ith day, find the maximum profit that can be achieved by buying on one day and selling on a later day.

If no profit is possible, return "0".

💡 Example

Input: prices = [7,1,5,3,6,4]
Output: 5

Explanation

Buy at price "1" and sell at price "6".

Maximum profit = "6 - 1 = 5"

💻 Language

Java

📂 File

"BestTimeToBuyAndSellStock.java"

🧠 Approach

1. Store the minimum price found so far.
2. Traverse the array.
3. Calculate the profit for each price.
4. Keep track of the maximum profit.
5. Return the maximum profit.

⏱️ Complexity

- Time Complexity: O(n)
- Space Complexity: O(1)

🎯 Goal

To practice arrays, loops, and optimization techniques in Java.
